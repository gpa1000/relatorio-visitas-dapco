⚙️ Configurações

Cole aqui a URL do Web App do Google Apps Script conectado à planilha do gerente. A partir daí, toda visita salva é enviada automaticamente (precisa de internet no momento).

Como criar a planilha do gerente

1. No Google Sheets, crie uma planilha nova (ex: "Visitas DAPCO").
2. Com a planilha aberta, vá em Extensões → Apps Script (tem que ser por dentro da planilha, não em script.google.com direto — senão o script não enxerga a planilha).
3. Apague o conteúdo e cole o código abaixo.
4. Clique em Implantar → Nova implantação → tipo "App da Web".
5. Executar como: Eu. Quem pode acessar: Qualquer pessoa (não escolha "Qualquer pessoa com Google Workspace").
6. Copie a URL que termina em /exec e cole no campo acima.
7. Sempre que editar o script depois, precisa publicar de novo: Implantar → Gerenciar implantações → ícone de lápis → "Nova versão" → Implantar. Só salvar o script (Ctrl+S) não atualiza o link já publicado.

Toque no código para selecionar tudo e copiar.

💡 Teste rápido: abra a URL /exec direto no navegador do celular. Se aparecer {"ok":true,...}, a implantação está correta. Se aparecer uma tela de login do Google ou erro, o problema é o passo 5 ou 7 acima.

⬆️ Este código já inclui a função usada pelo botão "Importar da planilha" (histórico → Importar), que traz para o celular as visitas de um vendedor específico já registradas na planilha. Se você atualizou um script antigo, não esqueça do passo 7 (Nova versão) para o botão funcionar.

⬆️ Importar da planilha

Escolha de qual vendedor você quer trazer as visitas já registradas na planilha do Google Sheets para este celular. Visitas que já existem aqui (mesmo ID) não são duplicadas.
